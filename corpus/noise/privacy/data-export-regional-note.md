# Customer Data Export — Regional Note

## Regional scope

This note applies to **CA operations** and discusses customer data export. It is active for regional agents but is not a replacement for the global canonical page `brightcart/v1/privacy/data-export`.

## Global baseline

The global baseline summarized for agents is: This policy describes the self service export a verified customer can request for a copy of common BrightCart account data. A verified customer data export is normally prepared within 24 hours. When the export is ready, BrightCart sends a download link that remains valid for 48 hours. The link requires the customer to sign in again before download. Regional teams must start from that rule and then apply local obligations or carrier/bank constraints.
