# Lost Package Criteria — Regional Note

## Global baseline

The global baseline summarized for agents is: This article defines when a package can be treated as lost rather than merely delayed. It is used before a replacement or refund is approved for a shipment that stopped moving. A domestic package can be treated as lost after 5 consecutive calendar days with no new carrier scan.
